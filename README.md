# 起号神器 · Landing Page

> AI自动生成抖音昵称/头像/简介 — [qihao.lqint.cn](https://qihao.lqint.cn)

## 概览

本仓库为 **起号神器** 的 GitHub Pages 静态落地页。国风设计风格（宣纸底色、红金配色、毛笔字体），展示产品核心功能和使用流程。

## 产品功能

- **AI 昵称生成** — 输入赛道关键词，一次生成3个优质昵称
- **AI 头像制作** — 根据赛道风格自动生成头像
- **AI 简介编写** — 3版不同风格的简介
- **视频模板** — 付费生成带货/种草类视频
- **多音色配音** — 5种配音音色可选

覆盖美食、知识、探店、家居、数码、宠物等15个赛道。

## 技术栈

- 纯静态 HTML / CSS — 零依赖
- Google Fonts — Ma Shan Zheng + Noto Sans SC
- Responsive Design — 全端适配

## 部署

推送到 GitHub Pages 即可：

```bash
git push origin main
```

然后在仓库 Settings → Pages 中设置部署源。
